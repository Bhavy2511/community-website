# Initial Content Sources

The first event pages use selected public-facing material from the local GarbaRaas 2025 and Nutan Varsh Milan 2025 folders supplied with this project.

- GarbaRaas 2025 photographs are used for the GarbaRaas page and archive.
- Nutan Varsh Milan 2025 invitations and event photographs are used for the Nutan Varsh page and archive.
- The Gujarati Community Development Plan informs the vision timeline, including foundation, expansion, alumni network and legacy phases.

Financial sheets, response spreadsheets and other personal operational files are not imported into the website.
